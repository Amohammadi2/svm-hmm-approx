[ ] WEEK 1-3: HEAVY TAILS & TIME SERIES FUNDAMENTALS
-------------------------------------------------------------------------------
* Core Math Concepts to Learn:
  [X] Read up on the Autoregressive Order 1 (AR(1)) process. 
      Understand what conditions make it stationary (|phi| < 1).
  [X] Study the probability density function (PDF) of the Student-t distribution 
      as a Scale Mixture of Normals (SMN). 
  [X] Derive/write down on paper how a Gaussian distribution integrated across a 
      Gamma precision variable yields a Student-t distribution.

* Implementation Tasks (R/Python):
  [X] Write a script to simulate synthetic data from the model's core equations:
      - Return Eq. (2a):   y_t = b0 + b1*y_{t-1} + b2*exp(h_t) + exp(h_t/2)*e_t
      - Volatility Eq. (2b): h_{t+1} = mu + phi*(h_t - mu) + sigma_eta * n_t
  [X] Run your simulation first using simple Gaussian errors (e_t ~ N(0,1)).
  [X] Swap out the error term for a heavy-tailed Student-t distribution.
  [ ] Plot both simulated asset returns side-by-side to notice how heavy tails 
      create realistic market "shocks" and outliers.


[ ] WEEK 4-7: THE HIDDEN MARKOV MODEL (HMM) COMPUTATIONAL ENGINE
-------------------------------------------------------------------------------
* Core Math Concepts to Learn:
  [X] Read basic literature on Hidden Markov Models (HMMs).
  [X] Focus closely on the "Forward Algorithm" matrix recurrence.
  [X] Understand the paper's main trick: dividing the continuous log-volatility 
      space (h_t) into 'm' discrete grid steps to create a discrete Transition 
      Probability Matrix (Gamma).

* Implementation Tasks (C++ / Rcpp Engine):
  [X] Write a standalone C++ function (using Rcpp/Armadillo or raw vectors) 
      that receives an observed return vector 'y' and parameter vector.
  [X] Implement the recursive HMM Forward Algorithm step loop over time t:
      - Likelihood_approx = delta * P(y_1) * Gamma * P(y_2) ... * Gamma * P(y_T) * 1'
  [X] Check for arithmetic underflow: Implement this calculation in log-space 
      (Log-Sum-Exp trick) so your probabilities don't drop to absolute zero.
  [X] Unit Test: Pass your simulated data from Phase 1 into your C++ function. 
      Verify that changing parameters dynamically updates the log-likelihood values.


[ ] WEEK 8-12: THE BAYESIAN IMPORTANCE SAMPLING FRAMEWORK & REAL DATA
-------------------------------------------------------------------------------
* Core Math Concepts to Learn:
  [X] Learn about parameter constraint transformations:
      - Use Logit transform for boundaries like |phi| < 1.
      - Use Log transform for variances (sigma_eta > 0) to unconstrain optimization.
  [X] Study the mechanics of Maximum A Posteriori (MAP) estimation.
  [X] Study the workflow of Importance Sampling: drawing independent proposals 
      from an approximate Multivariate Normal shape and correcting them with weights.

* Implementation Tasks (Integration & Polish):
  [X] Pass your unconstrained C++ likelihood function into a generic numerical 
      optimizer (e.g., 'optim' in R or 'scipy.optimize' in Python).
  [X] Locate the absolute peak (MAP estimate) and output the Hessian matrix at 
      that coordinate peak.
  [X] Write a sampler routine to draw independent draws from a Multivariate 
      Normal distribution parameterized by your MAP peak and the inverse Hessian.
  [X] Calculate the individual importance weights for each drawn parameter 
      sample to extract your final posterior means and credible intervals.

* The Final Reward:
  [X] Download historical daily stock indices or currency exchange rate data 
      for your home country (e.g., from Yahoo Finance).
  [X] Clean the data by converting raw closing prices into daily log-returns:
      - r_t = ln(Price_t / Price_{t-1})
  [ ] Feed your country's real-world dataset directly into your C++ pipeline.
  [ ] Plot the extracted hidden volatility process (h_t) to map out your 
      country's economic market volatility trends across past decades!
